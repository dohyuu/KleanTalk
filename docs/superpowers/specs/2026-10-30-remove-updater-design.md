# 개인용 KleanTalk 업데이트 기능 제거

상태: 사용자 승인 완료 (2026-10-30)

## 목적과 완료 범위

원 제작자나 배포처가 향후 제공하는 업데이트로 현재 앱이 교체되는 경로를 없앤다.
현재 소스를 기준으로 개인용 앱을 빌드하고 실행하며, 로컬 광고 서버·인증서·hosts 설정을 설치한 뒤 실제 카카오톡 광고 차단까지 확인한다.
작업은 기존 업데이트 기능을 삭제하는 작은 변경으로 제한한다.

## 검토한 접근과 선택

- 설정만 변경: 수정량은 가장 작지만 저장된 사용자 설정, 창을 열 때의 별도 확인, 개발용 자동 설치 경로까지 차단하지 못한다.
- 수동 업데이트만 허용: 자동 동작을 제한하면서 업데이트 기능을 보존한다. 사용자가 업데이트를 실행하면 기존 배포처의 코드를 받으며 Sparkle도 남는다.
- 업데이트 기능과 의존성 삭제: 삭제 범위는 더 넓지만 앱 내부의 조회·다운로드·교체 경로가 없어진다. 사용자가 마지막 지시에서 이 방식을 선택했다.

## 변경 범위

1. `Sources/KleanTalk.swift`: Sparkle import, updater 생성·delegate, 자동·수동 확인과 설치, 업데이트 상태·버튼·메뉴·번역, 업데이트용 환경 변수와 미리 보기 코드를 삭제한다. 버전 줄에는 현재 앱 버전만 표시한다.
2. `Info.plist`: 업데이트 피드 주소, 공개 서명 키, 자동 확인·확인 주기 등 Sparkle 설정을 삭제한다. 업데이트 시험용으로만 사용하던 로컬 네트워크 예외는 기존 광고 서버 점검에 필요한지 확인한 후 제거 여부를 결정한다.
3. `build.sh`: Sparkle 다운로드·압축 해제·링크·번들 복사·서명과 업데이트 시험용 빌드 번호 덮어쓰기를 제거한다. 기존 universal 빌드와 앱·로컬 서버의 ad-hoc 서명은 유지한다.
4. `scripts/release.sh`: 업데이트 zip·서명·피드를 생성하고 기존 배포처에 게시하는 스크립트 전체를 삭제한다. 로컬 DMG 생성 스크립트는 유지한다.
5. `README.md`, `docs/DEVELOPMENT.md`: 자동 업데이트·배포 설명을 제거하고 로컬 빌드·실행 방법으로 바꾼다. 기존 배포처의 DMG를 받으라는 설치 안내도 로컬 빌드 안내로 교체한다.

## 유지할 동작과 제약

- 광고 서버, hosts 설정, 인증서, 로그인 실행, 상태 점검, 제거 기능을 유지한다.
- 설치된 서버와 앱에 포함된 서버의 차이를 검사하는 기능을 유지한다. 다시 설치 안내는 로컬 서버를 설치한다는 의미로 바꾼다.
- 버그 신고 링크는 업데이트 공급 경로가 아니므로 유지한다.
- 이후 앱 교체는 사용자가 소스를 선택해 직접 빌드하는 방식이다. 현재 소스 자체의 무해성이나 모든 보안 문제의 해결을 보증하지 않는다.
- 기존 설치·실행 중인 앱과 로그인 항목을 확인하여 예전 앱이 계속 동작하지 않도록 전환한다. 이 앱과 무관한 프로세스나 설정은 변경하지 않는다.
- 관리자 암호와 인증서 신뢰 확인은 macOS 화면에서 사용자가 직접 처리한다. 암호를 수집하거나 우회하지 않는다.

## 검증과 인도

- 실행 소스·설정·빌드·배포 경로에 업데이트 주소와 Sparkle 호출이 남지 않았는지 검사한다. Git 과거 기록과 이 설계 문서의 설명은 삭제 대상이 아니다.
- 셸 문법과 plist 유효성을 검사하고 기존 arm64·x86_64 빌드를 수행한다.
- 산출물의 연결 라이브러리와 번들 내용을 검사해 Sparkle 및 updater helper가 없음을 확인하고 서명을 검사한다.
- 앱을 실제 실행하여 메뉴와 상태 화면에 업데이트 동작이 없고 설치·복구 UI가 동작하는지 확인한다.
- 사용자용 경로에 빌드한 앱을 설치하고 앱의 설치 흐름으로 서버·hosts·인증서를 구성한다.
- 서비스 상태, 전용 루프백 연결, 인증서 검증 및 빈 광고 응답을 확인한다. 카카오톡을 재실행하고 화면에서 광고 차단을 확인한다. 화면 확인이 불가능하면 사용자에게 시각 확인을 요청하고 기술적 점검 결과와 구분한다.

## 구현자에게 남기는 선택

세부 코드 정리와 검증 도구는 기존 구조를 따라 결정한다. 새 업데이트 대체 기능, 광범위한 리팩터링, 별도 배포 체계는 만들지 않는다.

## 승인 후 추가 지시

사용자가 개인용 앱 이름을 `NoAdsTalk`으로 지정했다. 표시 이름과 앱·실행 파일·DMG 산출물 이름을 변경하여 `~/Applications/NoAdsTalk.app`으로 설치한다. 사용자가 앱을 직접 실행·설치하기로 했으므로 실제 광고 차단 확인은 사용자 실행 뒤 진행한다.
